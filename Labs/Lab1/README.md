# Lab 1: SCM Setup and Baseline Creation

This individual starter project separates student data, demonstration logic,
and reusable score helpers.

## Files

- `students.py` contains the sample student records.
- `utils/helpers.py` calculates the highest and lowest scores.
- `app.py` displays the sample records and score summary.
- `requirements.txt` records the dependency baseline (standard library only).
- `RELEASE_NOTES.md` records the v1.0 baseline.

## Run

From this directory:

```powershell
python app.py
```

## SCM evidence

The starter baseline is tagged `v1.0` in the repository. Capture the folder
structure, a successful run, and the actual Git commit/tag history for the
report. Branch protection and review rules can be inspected on the GitHub
repository's `main` branch.
