# SEN 401 SCM Lab

An individual lab project demonstrating modular Python code and Software
Configuration Management practices.

## Project structure

- `app.py` runs the demonstration and displays score statistics.
- `students.py` stores sample student records.
- `utils/helpers.py` contains reusable highest- and lowest-score functions.
- `requirements.txt` documents the project's dependency requirements.
- `Lab4/` contains the reverse-engineered FastAPI and SQLite migration.

## Run the application

Python 3.10 or later is recommended.

```powershell
python app.py
```

The starter project uses only the Python standard library, so no package
installation is required.

## Assessment work
