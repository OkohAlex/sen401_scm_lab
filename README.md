# SEN 401 SCM Lab

An individual lab project demonstrating modular Python code and Software
Configuration Management practices.

## Project structure

- `app.py` runs the demonstration and displays score statistics.
- `students.py` defines validated sample student records using Pydantic.
- `utils/helpers.py` contains reusable highest-, lowest-, and median-score functions.
- `requirements.txt` documents the project's dependency requirements.

## Run the application

Python 3.10 or later is recommended.

```powershell
python -m pip install -r requirements.txt
python app.py
```
